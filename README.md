# Software Supply Chains

A research program of the [Duality Lab](https://davisjam.github.io/), led by
James C. Davis at Purdue University.

Establishing justified trust in software assembled from artifacts and actors outside an engineer's direct control.

This repository hosts the program's project site, published at
<https://davisjam.github.io/software-supply-chains/>.

The site is under construction.
